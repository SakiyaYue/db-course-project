# 脚本复现与截图清单

本说明对应当前提交脚本。使用 SSMS，由数据库管理员执行；实验报告只选代表性结果截图，不需要逐条截完所有用例。

已收集的19张截图按类别整理在[结果目录](../figure/README.md)。该目录标明每张图的内容及仍需补充的权限对比结果，下面的截图清单作为选取建议。

## 1. 执行方式与顺序

1. 连接本机 SQL Server，当前电脑使用 `localhost`、Windows 身份验证；其他电脑使用自己的实例名。
2. 通过“文件 → 打开 → 文件”打开项目根目录的 SQL 文件。每个文件使用新的查询窗口，不选中局部文字，按 F5 完整执行。
3. 每一步查看“结果”和“消息”。出现未捕获错误时先处理错误，再继续下一步。约束及权限反例中的 `actual_error` 非空是预期拒绝，是否通过看 `result`。

**第一步会删除并重建现有 TeabarDB。仅在首次初始化或需要重置课程数据库时执行；有需要保留的数据时不要运行建库脚本。**

| 顺序 | 脚本 | 作用与应检查的结果 |
| --- | --- | --- |
| 1 | `db_creation.sql` | 创建 TeabarDB 和15张空业务表，无执行错误 |
| 2 | `seed_data.sql` | 装载样例；消息显示“15张表，共232条记录” |
| 3 | `constraint.sql` | 安装约束并自动验证；汇总 `passed_cases = 44`，用例均为“通过” |
| 4 | `role.sql` | 安装四种角色、六个演示用户和业务接口；汇总 `passed_cases = 84`，用例均为“通过” |
| 5 | `view.sql` | 创建13个 `dbo` 正式视图，执行文件末尾的验证查询 |
| 6 | `query.sql` | 执行Q01—Q18全部查询，保留默认输入作基准结果 |
| 7 | `crud_demo.sql` | 演示增删改查、扣返库和积分；消息显示成功且已回滚 |
| 8 | `query.sql` | 再次查询，确认业务样例恢复，经营统计仍为原值 |
| 9 | `view_demo.sql` | 演示测试视图创建、修改、删除；结果依次为4行、2行、“已删除” |
| 10 | `query_demo.sql` | 用较少的结果集展示关键词、时间范围和单日期查询，便于截图 |

第9—10步是便于展示的补充演示。`query.sql` 的Q17、Q18依赖 `view.sql`，不能跳过视图安装。

角色安装后总表数为16：15张业务表加 `teabar_auth.PrincipalBinding`。正式统计视图是13个 `dbo` 视图，`teabar_api` 下还存在权限接口视图，因此不要用全库视图总数判断是否正确。

约束及角色验证会回滚测试数据，但保留安装对象；CRUD演示结束回滚全部演示修改；视图演示最后删除专用测试视图。六个角色演示用户是 `WITHOUT LOGIN` 用户，脚本已经通过 `EXECUTE AS USER` 验证，不需要分别用六个账户登录SSMS。

## 3. 补充检查与重复演示

初始化后可在新查询窗口执行以下只读检查，方便截图：

```sql
USE TeabarDB;
GO
SELECT COUNT(*) AS product_count FROM dbo.Product;       -- 4
SELECT COUNT(*) AS ingredient_count FROM dbo.Ingredient; -- 9
SELECT COUNT(*) AS order_count FROM dbo.SalesOrder;       -- 5
SELECT COUNT(*) AS item_count FROM dbo.OrderItem;         -- 7
```

全部演示结束后，可再次核对恢复结果及订单金额：

```sql
USE TeabarDB;
GO
SELECT product_id, base_price, status FROM dbo.Product
WHERE product_id = 'P001'; -- 6元，在售
SELECT ingredient_id, stock, unit FROM dbo.Ingredient
WHERE ingredient_id = 'I001'; -- 5000g
SELECT member_id, points FROM dbo.Member
WHERE member_id = 'M001'; -- 120分
SELECT order_id FROM dbo.SalesOrder
WHERE order_id IN ('CO001', 'CO002'); -- 0行
SELECT order_id, total_amount, amount_matches_items
FROM dbo.vw_OrderSummary ORDER BY order_id; -- 5行，核对列全部为1
```

遗漏截图时重新完整运行对应演示脚本，查看结果窗格即可。不要为了截图只执行CRUD内部的局部写入语句；脚本运行完后临时数据已经回滚，应从保留的结果集中截图。

`seed_data.sql` 要求空业务表，不能在已有样例上重复装载。重新演示一般只需运行约束、角色、CRUD或两个demo脚本；只有从空库完整复现时才重新运行建库和装载。统计日期使用样例日期2026-10-04，不要直接替换成当天日期。
