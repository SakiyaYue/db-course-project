# C 页面与角色操作矩阵（第一至第七部分）

日期：2026-11-10。沿用 A/B 已交付的 Flask/Jinja + Service 架构及固定演示账号，不改变数据库关系模式或业务过程。范围仅为 C 清单第一至第七部分，第八部分起的交付与完整展示工作不在本轮勾选。

## 角色和页面

| 角色 | 固定演示登录名 | 导航/页面 | 允许操作 | 必须拒绝 |
| --- | --- | --- | --- | --- |
| 未登录 | 无 | `/menu`、商品详情、`/login` | 浏览可售目录、登录 | 写入及受保护页面；HTML 转登录 |
| 顾客 | guesta、guestb | 菜单、`/orders/new`、`/my/orders`及详情 | 多商品模拟付款、本人排队订单退款、本人消耗快照 | 他人订单、会员资料、员工/店长操作 |
| 会员 | membera、memberb | 顾客页面及 `/my/profile` | 本人姓名/电话/积分只读，购买及退款 | 修改积分、他人资料、员工/店长操作 |
| 店员 | clerk1 | `/work/orders`、订单详情、`/work/team` | 当天/全部未完成筛选、状态推进、排队订单协助退款、会员登记更正 | 库存写入、改价、工资、维护中心、历史订单 |
| 店长 | manager1 | 店员页面、统计、库存、会员、员工、维护中心、历史订单 | 9 类资料维护、补库盘点、历史筛选分页/只读详情 | 直接修改历史快照、物理删除核心订单 |

演示密码沿用[账号初始化说明](演示账号与初始化.md)，不另建固定真实凭据。登录表单 `login_name,password,csrf_token,next`；退出 POST `/logout`。每次请求复核账号会话版本，失效后清会话并跳转登录；API 保持 401。导航隐藏只是展示，页面路由和 Service 保留角色检查，HTML 越权返回友好 403。

## 新页面与后端字段

| 页面 | 输入/数据来源 | 行为 |
| --- | --- | --- |
| `/admin/maintenance` | 固定 9 类分类 | 维护中心与配置顺序说明 |
| `/admin/maintenance/<resource>` GET | 已有维护 Service 列表；`key` 为 `/` 分隔主键 | 全状态列表、新增表单、编辑回填；表格横向滚动 |
| 同路径 POST | 既有维护字段 + `csrf_token`；移除使用 `operation=remove` | Service 校验；成功重定向，失败保留输入与实际错误状态 |
| `/admin/orders` | `order_id,member_id,status,date_from,date_to,page,page_size` | 空筛选省略；稳定排序、前后页、无结果提示 |
| `/admin/orders/<id>` | History Service | 订单明细/规格/加料/消耗快照只读，无写入按钮 |
| `/my/profile` | 会员本人 Service | 编号、姓名、电话、积分只读 |

维护字段与状态完全复用[管理契约](管理维护接口-给C.md)，历史与退款使用[订单会员契约](订单与会员补充接口-给C.md)。维护表单编号支持字母、数字、下划线、短横线；编辑时主键只读。商品默认下架、商品规格默认停用；基础配方保存/移除后提示重审规格。库存入口独立于原料基础资料。

## 业务含义与交互

- 商品价格、规格差价、加料价格共同形成每杯价格；结算页面用整数分计算预览，乘数量得到明细小计及合计。最终成交金额由后端确认。
- 库存是当前可用数量；库存不足由数据库拒绝整单，页面保留购物篮并展示友好提示。
- 积分只在订单首次完成时结算，不提供用户自行修改入口。
- 状态流转为排队中→制作中→待取餐→已完成；仅排队中可退款。成功回到工作列表，避免旧日期订单完成/取消后离开工作范围造成详情 404。
- 成交价格、规格/加料名称和消耗用量展示保存的快照；原料名称是当前标签，不伪称独立名称快照。
- 规格必须显式选择，数量 1–99，每单 1–20 项；可选择模拟付款失败。提交后禁用按钮；下单复用已有请求标识，后端幂等仍是最终保证。
- 其他表单成功 POST/Redirect/GET，刷新不重复提交；前端禁用重复点击，浏览器返回时恢复按钮。退款和维护/移除/盘点均提供确认提示。
- 数值使用有限范围、两位小数、正负规则；时间表单校验先后；会员姓名最多 50 UTF-16 单位，手机号 `1[0-9]{10}`。
- 共用布局、角色导航、状态标签、提示组件、确认交互、空结果、移动端表单与滚动表格；错误页包含返回入口，不展示 `detail`、SQL、连接信息或堆栈。
- 503 显示服务不可用与重试建议，提醒先查订单确认提交结果；401 引导登录；非法编号、重复退款、冲突和超时使用后端友好消息。
