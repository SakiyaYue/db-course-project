# 演示账号与初始化

## 1. 演示账号

由 `database/admin/init_web_accounts.py` 创建，仅用于课程演示与本地测试：

| 登录名 | 密码 | app_role | 数据库用户 | 说明 |
| --- | --- | --- | --- | --- |
| `guesta` | `Guest#2026` | customer | `web_guest_a` | 游客 A，独立购买身份 |
| `guestb` | `Guest#2026` | customer | `web_guest_b` | 游客 B，用于验证本人隔离 |
| `membera` | `Member#2026` | member | `web_member_a` | 会员 M001（陈晨，120 分） |
| `memberb` | `Member#2026` | member | `web_member_b` | 会员 M002（刘洋，60 分） |
| `clerk1` | `Clerk#2026` | clerk | `web_clerk` | 店员，工作台与状态推进 |
| `manager1` | `Manager#2026` | manager | `web_manager` | 店长，统计、库存、员工、会员维护 |

说明：

- 登录名刻意不含 `_`/`-`，绕过 v1.0 `CK_WebAccount_LoginName` 缺陷（见[给 A 的缺陷反馈](给A的缺陷反馈.md)）；用户显示名仍是 `web_guest_a` 等，由 `principal_name` 映射。
- 密码只以 PBKDF2 哈希存入 `teabar_auth.WebAccount`；文档中的明文仅用于本地演示，真实部署必须更换并妥善保管。
- `account_id` 因库而异且会随重置变化：本次重置后工作库为 7–12、测试库为 1–6（自增号从 `WebAccount` 历史值继续）。应用不依赖固定 `account_id`，只把它写进会话。
- 这些账号是 Web 账号；SQL 回归用的 `demo_* WITHOUT LOGIN` 用户仍保留，不用于 Web 登录。

## 2. 初始化（管理员一次性操作）

前提：目标库已是 v1.0（含 `teabar_auth.WebAccount`、两个认证过程），连接账号为 `db_owner/sysadmin`。

```powershell
# 工作库
python database\admin\init_web_accounts.py --database TeabarDB_Phase2_Work

# 测试库（pytest 用）
python database\admin\init_web_accounts.py --database TeabarDB_Phase2_Test

# 只演练、不写库
python database\admin\init_web_accounts.py --database TeabarDB_Phase2_Test --dry-run

# 重置演示密码（递增 session_version，使旧会话失效）
python database\admin\init_web_accounts.py --database TeabarDB_Phase2_Test --reset-passwords
```

脚本可安全重复执行：角色、用户、角色成员关系、授权、绑定、账号都是"存在则校正、缺失则创建"，已有密码哈希不会被覆盖，除非显式 `--reset-passwords`。

## 3. 测试库 `TeabarDB_Phase2_Test`

pytest 默认连接独立测试库。当前新环境不依赖旧备份或旧D盘路径：

```powershell
python database/admin/prepare_test_database.py --database TeabarDB_Phase2_Test
python database/admin/prepare_test_database.py --database TeabarDB_Phase2_Work
```

仅当目标库不存在时执行。已有 v1.0 库用 `init_web_accounts.py --database ...` 安装账号及B扩展，工具不会自动删除或覆盖库。

## 4. 应用配置

复制 `.env.example` 为 `.env` 并修改：

```ini
TEABAR_DB_DRIVER=ODBC Driver 18 for SQL Server
TEABAR_DB_SERVER=localhost
TEABAR_DB_NAME=TeabarDB_Phase2_Work
TEABAR_DB_TRUSTED=1
TEABAR_SECRET_KEY=请替换为随机密钥
TEABAR_SESSION_COOKIE_SECURE=0
```

- `TEABAR_DB_NAME` 决定页面读写哪个库；测试通过环境变量强制指向 `TeabarDB_Phase2_Test`。
- `.env` 已被 `.gitignore` 排除，只提交 `.env.example` 占位值。
- 连接串自动附加 `TrustServerCertificate=yes` 与 5 秒连接超时。

初始化现在自动安装 `web_backend_extensions.sql`；`--dry-run` 对账号、授权、公开菜单、幂等表/过程及字符类兼容补丁一并回滚。新库工具也会调用该初始化路径。
