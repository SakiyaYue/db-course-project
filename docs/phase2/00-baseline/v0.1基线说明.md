## 2. 数据库与工具要求

- 数据库名称：`TeabarDB`。
- 数据库平台：Microsoft SQL Server。
- 已有操作文档使用 SSMS 19；SSMS 是管理工具，不等同于 SQL Server 引擎版本。
- 已有本机示例连接为 `localhost` 和 Windows 身份验证；其他电脑应使用自己的实例名。
- SQL Server 精确版本、版本号和数据库兼容级别尚未在当前仓库中固化，必须在第 4 轮从实际复现环境读取。
- `db_creation.sql` 会删除并重建已有 `TeabarDB`，不能对需要保留数据的数据库执行。

## 3. 正式安装顺序

| 顺序 | 脚本 | 职责 | 对最终数据库的影响 |
|---:|---|---|---|
| 1 | `db_creation.sql` | 删除并重建 `TeabarDB`，创建 15 张空业务表 | 改变结构；破坏性初始化 |
| 2 | `seed_data.sql` | 向空业务表装载 232 条样例 | 改变数据；不能在已有样例上重复执行 |
| 3 | `constraint.sql` | 补齐并核验字段、默认值、PK/UK/FK/CHECK 和计算列兼容性，运行 44 项正反例 | 改变并保留结构；验证数据回滚 |
| 4 | `role.sql` | 安装两类架构、身份绑定表、TVP、函数、接口视图、过程、四种角色和六个演示用户，运行 84 项验证 | 改变并保留安全与业务接口对象；测试数据回滚 |
| 5 | `view.sql` | 创建 13 个正式 `dbo` 查询/统计视图 | 改变并保留结构 |
| 6 | `query.sql` | 执行 Q01—Q18 查询验证 | 只读，不改变最终结构 |
| 7 | `crud_demo.sql` | 演示商品、库存、订单、退款、积分和删除 | 事务内演示，结束回滚 |
| 8 | `query.sql` | 再查关键结果，确认演示回滚 | 只读 |
| 9 | `view_demo.sql` | 创建、修改并删除 `dbo.vw_DemoProduct` | 临时演示对象，结束时删除 |
| 10 | `query_demo.sql` | 展示关键词、时间范围和每日经营统计 | 只读 |

`query.sql` 的 Q17、Q18 和 `query_demo.sql` 依赖 `view.sql`。完整 v0.1 不能只理解为 `db_creation.sql` 创建的 15 张表，还包括 `constraint.sql`、`role.sql` 和 `view.sql` 安装的持久对象。
