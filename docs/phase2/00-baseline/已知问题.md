# v0.1 已知问题

核对日期：2026-11-06。本清单集中登记结构、业务过程、认证、文档和证据问题。它不是 v1.0 变更决定；涉及业务含义的项目必须由小组确认，并在第五周设计审查后再决定是否迁移。

## P2-001 逐明细消耗快照下限未完整校验

- 问题描述：ER 规则要求每条订单明细有 `1..N` 条原料消耗快照，但 `usp_PlacePaidOrder` 目前只检查整单汇总原料集合非空。
- 业务证据：某条明细全部原料用量为 0、同单另一条明细有用量时，整单检查可能通过；查询和退款会把缺快照视为异常。
- 影响范围：下单、退款、库存审计、ER 基数说明和回归测试。
- 当前实现：尚无逐 `item_id` 的非零快照检查；现有 84 项角色用例不覆盖该反例。
- 建议方向：先确认零消耗明细是否允许；若不允许，在过程内逐明细拒绝并增加反例。
- 计划阶段：第 5 周确认规则，第 6 周迁移/接口升级和回归。
- 影响迁移：是。影响 Web：是。
