主要结论：14 张表在本文列明的业务依赖下可判为 BCNF；`ItemSpec` 满足 3NF、未满足 BCNF；`OrderItem` 若将派生列 `sub_amount` 纳入关系，则存在违反 3NF 的函数依赖，排除派生列的基础事实投影满足 BCNF。不能统一写成“16 张表全部满足 3NF”。

共同决策以 [PHASE2-DECISIONS.md](../../../PHASE2-DECISIONS.md) 为准，用户已确认对齐。现状分析与v1.0目标文档分别标明范围，不把目标 `WebAccount` 当成已存在对象，也不以样例数据的偶然唯一性证明函数依赖。
