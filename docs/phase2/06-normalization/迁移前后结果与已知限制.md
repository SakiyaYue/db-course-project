## 4. 本次运行修正

1. SQL Server把冻结过程头部CREATE OR ALTER保存为CREATE加空白。预检现仅允许冻结原文或该已验证改写的完整哈希，正文仍须完全一致。
2. sys.key_constraints/sys.check_constraints含TVP内部约束；持久表计数改为显式连接sys.tables，保留TVP不动。
3. CREATE SCHEMA测试准备放入独立无参数批次，避免参数化批次解析错误。
4. 被拒绝的EXECUTE AS会使显式事务失效，最后一个反例移到事务外隔离运行；数据和安全配置清理仍由总核验确认。

原始失败尝试保留于[attempts](../../../results/phase2/migration/attempts/)，没有用最终成功覆盖失败历史。上述运行修正完成后重新执行完整回归，最终184项通过；最终脚本默认迁移开关仍为0/0。
