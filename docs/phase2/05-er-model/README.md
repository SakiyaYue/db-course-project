# 第 5 周 ER 模型工作区

本目录保存第五周分析材料。分析以冻结 SQL 为事实基础，可以与 SSMS 基线采集并行；数据库实证结果返回后再补充验证结论，不提前决定结构修改。

## 输入

- `v0.1` SQL 和 [对象清单](../00-baseline/对象清单.md)；
- 根目录 `ER图_修订版.png`；
- 第一阶段数据字典、ER 核对记录和角色说明；
- [已知问题](../00-baseline/已知问题.md)；
- 课程第五周要求：实体、属性、主码、候选码、外码、联系、最小/最大基数、参与约束和业务规则映射。

## 禁止事项

- 不因样例数据恰好唯一就推断业务候选码；
- 不把外键存在误写成“父对象至少有一个子对象”；
- 不为了展示规范化而强行拆表；
- 不在业务规则确认前修改 v0.1 SQL 或编写最终迁移脚本。
