## 目录原则

- 第一阶段 SQL 继续留在根目录，避免旧链接和复现说明失效。
- 第二阶段新增 SQL 进入 `database/`，新增设计材料进入 `design/`，新证据进入 `results/phase2/`。
- `NEW-TODO/` 保存课程任务原件和本地详细清单，继续由 Git 忽略。
- 不在第五周分析完成前修改业务结构或伪造迁移占位脚本。
