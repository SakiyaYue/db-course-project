# 组员 C 待办清单：前端、测试、文档与课堂展示

## 你的职责

你是前端、测试证据和最终交付主负责人，负责角色页面、表单校验、端到端测试、结果目录、README、报告整合和课堂展示。你拥有模板、静态资源、端到端测试材料和最终交付文档的主要编辑权。

你不在模板中写 SQL，也不自行修改数据库对象。需要后端字段时与组员 B 确认，需要数据库业务语义或迁移结果时向组员 A 获取证据。

## 标记说明

- **[可并行]**：无需等待其他组员，可以立即进行。
- **[共同决策]**：三人确认后冻结。
- **[依赖 A]**：需要组员 A 的数据库设计、迁移或回归结果。
- **[依赖 B]**：需要组员 B 的路由、字段、会话或错误接口。
- **[依赖 A+B]**：需要数据库和后端均完成对应能力后才能进行。
- **[依赖前项]**：必须在本清单前置任务完成后进行。
- **[联调]**：需要与 A 或 B 一起验证。
