## 你的职责

你是后端和集成主负责人，负责让 Web 应用安全、参数化地访问 SQL Server，并打通登录、顾客下单、本人订单、店员状态推进、完成积分和退款返库。你拥有应用配置、数据库连接、DAO、Service、Route、会话、异常和日志模块的主要编辑权。

你不直接决定数据库关系模式，也不要在页面或 Service 中拼接 SQL。数据库对象需要变化时，把需求交给组员 A；页面字段或交互改变时，把接口约定交给组员 C。

## 标记说明

- **[可并行]**：无需等待其他组员，可以立即进行。
- **[共同决策]**：三人确认后冻结。
- **[依赖 A]**：需要组员 A 提供数据库对象、过程或迁移结果。
- **[依赖 C]**：需要组员 C 提供页面输入或交互约定。
- **[依赖前项]**：必须在本清单前置任务完成后进行。
- **[依赖 DAO]**：必须先完成对应的数据访问方法。
- **[依赖 Service]**：必须先完成对应业务服务，再验证其规则与事务。
- **[联调]**：需要与 A 或 C 一起验证。
