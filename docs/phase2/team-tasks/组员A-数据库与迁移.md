# 组员 A 待办清单：数据库设计、迁移与回归

## 你的职责

你是数据库主负责人，负责把已经冻结的 v0.1 设计为可解释、可迁移、可回归的 v1.0。你拥有 `database/migrations/`、`database/regression/`、`design/er/v1.0/` 和规范化文档的主要编辑权。

你不负责大量 Web 页面，也不要直接修改组员 B 的后端结构或组员 C 的页面。应用需要数据库变更时，先把对象名、参数、返回列和错误码写成接口约定，再交给组员 B 接入。

## 标记说明

- **[可并行]**：无需等待其他组员，可以立即进行。
- **[共同决策]**：三人确认结论后才能冻结，但可以先准备方案。
- **[依赖 B]**：需要组员 B 提供应用接口或安全需求。
- **[依赖前项]**：必须在本清单前置任务完成后进行。
- **[依赖目标模式]**：必须先冻结 v1.0 目标关系模式和对象变更清单。
- **[依赖 migration]**：必须先成功执行迁移脚本并得到可验证的 v1.0 工作库。
- **[联调]**：需要与组员 B 或 C 一起验证。
