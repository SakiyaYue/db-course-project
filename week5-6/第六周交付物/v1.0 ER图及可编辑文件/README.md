## 图例与基数

Mermaid 源码使用 `classDiagram` 表达关系模式。实线表示外键，虚线表示 SID、购买身份或值班时间的逻辑关联。`PK` 为主码，`UK` 为唯一约束参与列，`FK` 为外键参与列；复合键按数据字典中的组合解释。`CK-derived` 表示推导候选码，`nullable` 表示可空，`computed` 表示计算列。PNG 中可空列使用 `?` 标记，新增的 WebAccount 表使用蓝色表头。

订单到明细、明细到原料消耗的 `1..*` 下限由下单过程保证。ItemSpec 的 `0..3` 表示结构允许的选择数；成交时须为商品配置的每种规格类型选择恰好一个，至多三类。加料选择可为空。

WebAccount 与 PrincipalBinding 按 SID 关联，双方至多一个。购买账号要求活动绑定，工作账号按角色核验。数据库用户 SID 由身份初始化和上下文过程核验。

订单与值班按 `start_time <= order_time < end_time` 匹配，可同时对应多人；订单与绑定按购买身份匹配，同一会员可以存在多个绑定。

## 编辑与导出

使用支持 Mermaid 的编辑器打开 `.mmd` 文件，即可预览和修改。分图保留对应表的完整字段，以及这些表之间的关联；修改公共字段或关系时，同步更新总图和相关分图。

PNG 保留原有导出样式。更新源码后，可通过 Mermaid 编辑器重新导出图片；布局由渲染工具决定。图中的 TARGET / NOT INSTALLED 是原始设计阶段标记，迁移结果见[迁移前后结果与已知限制](../迁移前后结果与已知限制.md)。
