- “店员不能补库”：预期与实际错误229，结果通过。

- “店长也不能直接改历史成交快照”：预期与实际错误229，结果通过。

这些行不相邻时分两张截图；新图放在本目录的 `role/` 下。管理员连接名称出现在窗口顶部不影响实验，脚本内部使用 `EXECUTE AS USER` 切换身份，实际测试者看 `user_name`。
