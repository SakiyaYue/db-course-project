## 验证内容

1. 店员和店长协助退款精确返库，重复退款不重复返库，制作中/待取餐/已完成拒退，CSRF 保持有效；参考 HTML 退款页面及重定向可用。
2. 店长可查 2001 年的已取消订单，员工仍不能从工作详情读取该订单；列表支持日期包含结束当天、精确编号/状态过滤及分页。修改现价后详情仍返回原成交快照。
3. 顾客和会员均可读本人消耗，其他购买者 HTTP 返回 404；直接以另一购买者 SQL 身份查询本人消耗视图也无记录，直接读快照基表仍被拒绝。
4. 管理侧会员 POST 可保存并查询，店员/购买者不能使用该管理入口；50 单位姓名允许，超长姓名及非法手机号在数据库调用前拒绝，无静默截断。
5. 历史订单仅店长可读；未登录、跨角色访问均被拒绝；非法日期/页码/状态/注入字符串和重复过滤参数得到预期错误。
