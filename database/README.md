# 第二阶段数据库目录

本目录只保存第二阶段新增的数据库交付物。第一阶段的建库、样例、约束、角色、视图、查询和演示脚本继续保留在项目根目录，作为 `v0.1` 的稳定入口。

## 目录约定

- `migrations/v0.1-to-v1.0/`：第六周确定目标关系模式后保存迁移脚本、迁移说明和失败恢复说明。
- `regression/`：保存迁移前后回归脚本及其预期结果说明。
- 后续如需应用专用数据库接口或部署检查，再新增 `app-api/`、`deployment/`，不预先创建空框架。

## 当前状态

前三轮只建立目录和文档基线，尚未生成 `migration.sql` 或 `regression.sql`，也未修改任何现有 SQL。数据库实际复现需要在 SSMS 中另行完成。
