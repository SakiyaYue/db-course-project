# v0.1 ER 设计源

当前仓库中的 v0.1 清晰导出图仍位于根目录：[`ER图_修订版.png`](../../../ER图_修订版.png)。原可编辑源未纳入仓库，本轮已经依据冻结 SQL 和对象清单重建 [`ER图_v0.1.mmd`](ER图_v0.1.mmd) 作为可编辑 Mermaid 源。

可编辑源与导出图共同表达以下内容：

- 15 张业务表与 `teabar_auth.PrincipalBinding` 辅助表；
- 主码、候选码、外码和联合码；
- `0..1`、`1..1`、`0..N`、`1..N` 等最小/最大基数；
- 外键联系与值班时间匹配、购买身份核对等非外键业务联系的区别；
- 每条明细至少一条消耗快照目前是未完整落实的业务下限。

如果后续修改 Mermaid 源，必须同步重新导出清晰 PNG/PDF并重新核对字段、码和联系；不能只更新其中一种格式。v1.0 图应进入相邻的 `v1.0/` 目录，不覆盖本文件。
